# Unified Military Analytics & Comparison Dashboard (2025)

## 📌 Project Overview
An interactive intelligence suite that transforms raw defense data from 140+ nations into strategic insights. This project uses a Python-based pipeline to analyze military efficiency through custom KPIs.

## 🚀 Features
- **Global Intelligence:** Macro-trends in military spending.
- **Nation Deep-Dive:** Individual national military doctrines.
- **Rival Comparison:** Side-by-side "Versus" mode.
- **Coalition Builder:** Alliance strength simulation.

## 🛠️ Tech Stack
- **Environment:** Jupyter Notebooks
- **Language:** Python (BeautifulSoup, Pandas, NumPy)
- **Visualization:** Power BI / Tableau
- **Metrics:** DAX (Power BI) / Calculated Fields (Tableau)

## 📊 Key Metrics Engineered
- Assets per Million Population
- Defense Budget-to-GDP %
- Power Index Rank Gap
- Armor Intensity Index

## 📂 Folder Structure
- `notebooks/`: Jupyter Notebooks for Web Scraping and Data Cleaning.
- `scripts/`: Final Python scripts for automated data processing.
- `dashboards/`: Power BI (.pbix) and Tableau (.twbx) dashboard files.
- `data/`: Raw and Cleaned datasets (CSV/XLSX).
- `docs/`: Full project documentation and UI screenshots.
