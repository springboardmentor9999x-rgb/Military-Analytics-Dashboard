## Overview
This project focuses on collecting and preparing global military and defense-related data
from GlobalFirepower.com using Python-based web scraping.

The objective of this phase is **data collection and CSV generation**, which will later
support analytics and dashboard development.

## Data Source
- Website: https://www.globalfirepower.com
- Data is collected from multiple metric-specific pages listed in a text file.

## Files in This Branch
- `Infosys_project_webscraping.py`  
  Python script that scrapes country-wise military and economic metrics and generates a CSV file.

- `links_for_military_data.txt`  
  Contains metric URLs (one per line) used by the scraping script.
