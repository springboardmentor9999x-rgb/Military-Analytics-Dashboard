🛡️ Unified Military Analytics & Comparison Dashboard
📌 Project Overview

This project focuses on building a comprehensive data pipeline to collect, clean, and analyze global military statistics from GlobalFirepower.com.
The objective is to transform scattered web data into a structured, analysis-ready dataset that can later be used for dashboards, comparisons, and strategic insights.

This project simulates a real-world data engineering workflow, covering data extraction, cleaning, transformation, and preparation for analytics.
